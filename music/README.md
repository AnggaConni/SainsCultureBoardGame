## Not currently in the autoplay playlist

These files are preserved, but are not included in the public site's random playlist until their permission clearly covers this use case:
- `Mongolia (No Copyright Music) - No Copyright Music - Royalty Free Music.mp3` — the found source describes use in videos; permission for direct background playback in a website is not clearly established.
- `✔️Islamic Background Music_Arabic Music No Copyright_Oriental Music No copyright_Turkish Music - Power Music Factory.mp3` — the source description says use/download requires channel membership; the applicable permission was not verifiable from the repository.

A “no copyright” title is not itself a licence. Keep the original source details or written permission for every track. The player does not offer standalone MP3 downloads. Audio files that are outside this folder are not part of the playlist.
