# 3D models

Canonical upload folder for all 3D model files in the repository. Store every model directly here as a single .glb file, regardless of its subject.

Use lowercase snake_case names exactly as listed in the root ASSET_UPLOAD_GUIDE.md. Do not create category subfolders.

The expected-file manifest is data/asset_manifest.json. The monthly check is generated by scripts/audit_assets.py and published to the root ASSET_AUDIT_REPORT.md.
