# Local landscape models

Upload one GLB per named site environment. Registered paths are documented in the root `ASSET_CATALOG.md`.
- `komodo_island.glb`: generic/stylized island illustration for the Komodo learning mission, not an accurate geospatial reconstruction.
- `bali_subak_landscape.glb`: planned placeholder for a licensed Bali cultural-landscape model.
- `lorentz_highland_forest.glb`: planned placeholder for a licensed highland forest scene.
Use single-file GLB with embedded textures and optimise for browser loading.
