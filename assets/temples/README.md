# Temple assets

The World Heritage Atlas uses local GLB models in its site journal.

- `borobudur_temple.glb` already exists in this repository (about 2.38 MB), but its original creator and license are not documented here. Verify provenance before institutional/public distribution.
- `prambanan_temple.glb` is the target filename for the Prambanan/Candi Siwa model listed in the root `ASSET_CATALOG.md`.
- `borobudur_relief_3rd_floor.glb` is an optional relief detail model from PHAC (CC BY; attribution required).

Prefer GLB with embedded textures, optimize models for browser loading, and record source, creator, license and changes in `ASSET_CATALOG.md`.
